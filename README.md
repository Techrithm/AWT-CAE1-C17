# Student Event Registration Analyzer

## Description
A simple web application developed using HTML, CSS, and JavaScript to analyze student participation in technical events.

## Features
- Student Registration Form
- Input Validation
- Name Validation using Regular Expression
- Participation Level Analysis
- DOM Manipulation
- Array Iteration

## Technologies Used
- HTML 
- CSS 
- JavaScript

## Participation Levels
- 10 or more → Excellent Participation
- 5 to 9 → Good Participation
- Less than 5 → Needs More Participation
